# 变更日志（2026-04-22）

## 本次目标
- 修复首页手工导航配置在刷新后异常变化的问题。
- 让发布中心分类始终跟随首页手工维护后的导航。
- 支持首页导航配置跨浏览器/跨电脑保持一致（同一服务环境）。

## 主要变更
- 首页导航：
  - 固定“常用入口”分组显示在最上方。
  - 导航配置增加基于 `elementPath` 的稳定映射，入口地址变化时可继承原手工配置。
  - 导航配置读写增加 `updatedAt` 与服务端同步逻辑。
- 发布中心：
  - 分类计算与首页导航配置对齐，优先读取手工配置。
  - 同步支持 `elementPath` 回退匹配，避免仅按路由地址导致分类错位。
  - 修复导航配置写回时可能丢失字段（如 `routeOrder`）导致覆盖的问题。
- 本地服务接口：
  - 新增 `/api/nav-customize/state`（GET/POST）。
  - 新增 `.nav-customize-state.json` 作为导航配置持久化文件。
- 发布能力与样式/页面：
  - 同步了当前工作区内已完成的页面、样式与发布脚本相关更新。

## 影响说明
- 访问同一套服务与同一仓库目录时，首页导航配置可在不同浏览器/电脑间保持一致。
- 若手动清空本地站点数据，仍可从服务端状态恢复最新配置。

## 验证
- 执行构建：`npm run build` 通过。
